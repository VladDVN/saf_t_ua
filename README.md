# saf_t_ua
Це скрипт для створення структури бази даних в PostgreSQL. База даних містить в собі приклад заповненої готової структури для подальшого формування "стандартного аудиторського файлу" (Standard Audit File for Tax (SAF-T). Підійде для тих, хто не знає як підступитись до SAF-T, та з чого розпочати.
