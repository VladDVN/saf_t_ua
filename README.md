# SAF-T-UA

## Передмова
Ідея створення цього проекту виникла з причини, коли при заповненні структур saf-t файлу в програмі 1с:Предприятие 7.7 програма безпосередньо "вилітає" через якісь внутрішні обмеження обсягів даних.
Але можна записувати дані до бази даних Postgres, використовуючи ETL, або напряму, або через файл xml.

## Опис
Цей скрипт для створення структури бази даних в PostgreSQL. База даних містить в собі приклад заповненої готової структури для подальшого формування "стандартного аудиторського файлу" (Standard Audit File for Tax (SAF-T). Підійде для тих, хто не знає як підступитись до SAF-T, та з чого розпочати.
======================================
Чому саме така структура? - За цією структурою відповідальна особа (бухгалтер) зможе точково перевіряти дані, що будуть передані до Податкового органу.
Цей проект вирішує 2 проблеми:
1 - якщо програма постійно "вилітає";
2 - вирішує питання надто великих даних програм сімейства 1с BAS, BAF ( > 5 Tб)
